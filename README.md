# Java Programs

A collection of Java examples and practice programs for learning core Java concepts and improving problem-solving skills.

## Overview
This repository groups standalone Java source files and exercises. The exact topics and execution entry points are defined by the source files in the repository.

## Technology
- Java
- JDK (Java Development Kit)

## Getting Started
1. Install a JDK and verify it:
   ```bash
   java -version
   javac -version
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/JavaPrograms.git
   cd JavaPrograms
   ```
3. Compile and run a standalone class:
   ```bash
   javac ClassName.java
   java ClassName
   ```
   Replace `ClassName` with the public class containing the `main` method.

## Repository Contents
Explore the Java source files for individual examples. Some examples may require compiling related classes together.

## Learning Goals
- Practice object-oriented programming
- Understand Java syntax and standard library usage
- Develop debugging and problem-solving skills
